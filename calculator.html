How the numbers are built

  • Input speed is batch size × 512 ÷ first token time. GPU time per request is input tokens ÷ input speed, plus output tokens ÷ total output speed.
  • Busy GPU hours per day is requests × GPU time ÷ 3,600. Peak load is busy hours ÷ 24 × the peak factor. GPUs needed is the peak load ÷ the target utilization, rounded up.
  • GPUs billed is GPUs needed rounded up to a whole instance. Monthly cost is instances × price per instance hour × 730 hours. The GPUs are assumed to run all month.
  • For a GPU other than the T4, speed is the measured T4 speed × (its bandwidth ÷ 320), at the same share of the ceiling. Change the share of ceiling to test other assumptions. The guide measured 10% to 40%.

Measured on one NVIDIA T4 on 26 October 2026, with a 512 token prompt and 256 token answer, using Hugging Face Transformers. Prices are AWS on demand list rates for US East (N. Virginia), Linux, as reported by third party trackers on 20 November 2026. They leave out storage, data transfer and support, and they are not quotes. Bandwidths are published figures: T4 320, L4 300, A10G 600, A100 40 GB 1,555 and H100 SXM 3,350 GB/s. On AWS the A100 and H100 are sold only as 8 GPU instances. Input speed is derived from first token times and is approximate.
